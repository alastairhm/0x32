I have been thinking about running task on a Ubuntu Linux machine remotely using Twitter. Why you ask, due to firewall restriction where the machine is located I can't get direct access to it but it has connection out to the internet.<div><br /></div><div>So I thought I could send coded messages to it using Twitter and have it run certain tasks. Should be fairly easy to do in Python I thought, but what do use it for? Kicking off test runs, downloads or other system tasks?</div><div><br /></div><div>Downloads seemed a simple place to start, why max out my home broadband usage limit when I can get the remote machine to download things off-peak.</div><div><br /></div><div>For the proof of concept I decided to code it for using <a href="http://www.gnu.org/software/wget/">WGET</a> and a <a href="http://www.nuxified.org/blog/download_youtube_video_files_with_youtube_dl">command line YouTube down loader</a>.</div><div><br /></div><div>Using this<a href="http://code.google.com/p/python-twitter/"> Python Twitter API</a> I was able to get a proto-type running in a short time.</div><div><br /></div><div>Basically it should work like this,</div><div><br /></div><div><ul><li>I send a direct message to a Twitter account which only follows me and I follow on my main account.</li><li><a onblur="try {parent.deselectBloggerImageGracefully();} catch(e) {}" href="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEiNtEoLHP_C-rb7gfME9_OXmASUVfjz9X57OLc1lZoECbdUb3XpKCNZN7ZO8E_C7wfle2_Lyb_IqkpO14uhHI7vzzfdazXT-TooYZlaXF62Z6pJVnathnpio-bK-zrxwyvdGowvQteQKw0/s1600-h/twitter_dm.png"><img style="cursor:pointer; cursor:hand;width: 400px; height: 114px;" src="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEiNtEoLHP_C-rb7gfME9_OXmASUVfjz9X57OLc1lZoECbdUb3XpKCNZN7ZO8E_C7wfle2_Lyb_IqkpO14uhHI7vzzfdazXT-TooYZlaXF62Z6pJVnathnpio-bK-zrxwyvdGowvQteQKw0/s400/twitter_dm.png" border="0" alt="" id="BLOGGER_PHOTO_ID_5429523341741231250" /></a></li><li>This contains the code for type of download and the URL of the download.</li><li>The Python script is started by cron at scheduled times.</li><li>The script connects to Twitter and checks for direct messages.</li><li>It parses the direct message and either spawns a WGET or youTube-dl command to get the resource.</li><li>If its a video it then runs a command is run to convert it to<a href="http://www.divx.com/"> divX</a> ready for upload it to my phone.</li><li>If its a file then it is virus checked.</li><li>Finally the direct messages are deleted from the Twitter account and a reply sent to my Twitter account.</li></ul><div>So now without physical or remote access to the machine I can queue up downloads to retrieve during off peak hours.</div><div><br /></div><div>Now I've got it work, need to fine tune it to run other remote tasks, like restarting Weblogic or deploying new version of the application and running test suites.</div></div><div><br /><a href="http://meekgonkey.blogspot.com/">Doodle's Geek Monkey</a> by <a href="http://twitter.com/alastair_hm">Alastair Montgomery</a></div>
