The Vagrant file on <a href="https://github.com/alastairhm/pibuild">https://github.com/alastairhm/pibuild</a> sets up a build environment for building Raspberry Pi images from  the repository <a href="https://github.com/RPi-Distro/pi-gen">https://github.com/RPi-Distro/pi-gen</a>.<br />
<br />
I am using it to create a custom image minimal with <a href="https://www.docker.com/">Docker</a> pre-installed based on <a href="https://github.com/jonasrosland/pi-gen">https://github.com/jonasrosland/pi-gen</a>&nbsp;although you can edit the scripts to pre-install the packages you want in your image.<br />
