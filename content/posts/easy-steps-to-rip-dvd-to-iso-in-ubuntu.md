The file is an archive file specifically for DVD VIDEO_TS and AUDIO_TS files, and is an exact copy of the disc. ISO files can be quickly burned to a new dvd using standard burning software, making it the optimal choice for storing backups.<br /></div><div style="text-align:justify"><br />In Windows, third-party software is the only way to backup a DVD. Luckily, Ubuntu Linux has removed this need, and as a result, you can backup your dvds using a standard feature built into the OS --no software or Terminal required.<br /><br />This tutorial is written using Ubuntu 8.10 Intrepid Ibex. It will also work with 8.04.<br /></div><br /><div style="text-align:justify"><span style="font-weight:bold">Step 1:</span> Insert the DVD you wish to backup into your optical drive and wait for the dvd icon to appear on your Desktop.<br /><br /><span style="font-weight:bold">Step 2:</span> Right-click on the DVD icon and choose 'Copy Disc' from the menu.<br /><br /><span style="font-weight:bold">Step 3:</span> A dialog box will appear. In the drop-down box next to 'Copy to...', choose FILE IMAGE.<br /><br /><a href="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEjn8GTD_-opAqcDXdQgVc9RWZ9vY88p5EQ6QlTd133hesLuIYf_7LA_h-Fld3kvQb8gXbwQF4QOPPLZmphyyFYRgf-L1vBS64QWNifH3wSBBG52FnyECyb4TXilUsmJdXZdfW6MiR1Jb8w/s1600-h/Step+1_Choose+File+Image.png"><img style="margin:0px auto 10px;display:block;text-align:center;width:379px;height:250px" src="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEjn8GTD_-opAqcDXdQgVc9RWZ9vY88p5EQ6QlTd133hesLuIYf_7LA_h-Fld3kvQb8gXbwQF4QOPPLZmphyyFYRgf-L1vBS64QWNifH3wSBBG52FnyECyb4TXilUsmJdXZdfW6MiR1Jb8w/s400/Step+1_Choose+File+Image.png" alt="" border="0" /></a><br /><span style="font-weight:bold">Step 4:</span> Press the WRITE button.<br /><br /><span style="font-weight:bold">Step 5:</span> Choose a location to save the ISO.<br /><br /><a href="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEgTdUC-rNC_NhA6eVBlIXMlljiF-Qpf4zCkIRXN0Hz1OiQQtudFUApOHl9EixXqBuQv-Zc0pjtx3yoqEGsl_sMwMkZb8LdGyAZWrw648_OYbgA0EeJpE3ileEwQvMS1cLyTFbCngirzKww/s1600-h/Step+2_Save+as.png"><img style="margin:0px auto 10px;display:block;text-align:center;width:400px;height:327px" src="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEgTdUC-rNC_NhA6eVBlIXMlljiF-Qpf4zCkIRXN0Hz1OiQQtudFUApOHl9EixXqBuQv-Zc0pjtx3yoqEGsl_sMwMkZb8LdGyAZWrw648_OYbgA0EeJpE3ileEwQvMS1cLyTFbCngirzKww/s400/Step+2_Save+as.png" alt="" border="0" /></a><br /><span style="font-weight:bold">Step 6:</span> Wait for the progress bar to reach the end. It will say 'Successfully Copied'. Close the window and remove the DVD.<br /><br /><a href="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEiSphq8ryMNfKHIw3uM2Ig6FRsb1YmtJAI2oPXvoKldZB3GWPGbfETqnIemHGxoJj-eXwsxxklH4Q6WsmUjYG0V8GlU4a7Lw_s8B3GJ1Ya5lKi3DYqbKoWueELZfXnCxnMwEwrTLo6tWc0/s1600-h/Step+3_Copying.png"><img style="margin:0px auto 10px;display:block;text-align:center;width:377px;height:195px" src="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEiSphq8ryMNfKHIw3uM2Ig6FRsb1YmtJAI2oPXvoKldZB3GWPGbfETqnIemHGxoJj-eXwsxxklH4Q6WsmUjYG0V8GlU4a7Lw_s8B3GJ1Ya5lKi3DYqbKoWueELZfXnCxnMwEwrTLo6tWc0/s400/Step+3_Copying.png" alt="" border="0" /></a><br /><span style="font-weight:bold">Step 7:</span> You can test the ISO and confirm it works using VLC media player. If you don't have VLC installed, you can install it via the Terminal and this code: sudo apt-get install vlc .<br /><br /><span style="font-weight:bold">Step 8:</span> If you want to extract the VOB files from the ISO, right-click and choose 'extract here'. It will take about ten minutes, but the video_ts and audio_ts folders will be extracted to the same location.<br /><br /><span style="font-weight:bold">Step 9:</span> If you want to convert the ISO into a smaller file, such as an XviD or x264, you can either extract the VOBs and use DVD::RIP, or download Handbrake and rip directly from the ISO--both run smoothly on Ubuntu.<br /><br /><span style="font-size:85%;"> <span style="font-style:italic">Fair Warning: In some countries, backing up DVDs you legally own is not legal--for example, in the US, copying a commercial DVD violates the DCMA. Be sure to check with the laws in your country before proceeding.</span></span><br /></div><br /><blockquote>This tutorial was prepared for "Tech Source from Bohol" by <span style="font-weight:bold">Blair Mathis</span> of <a href="http://laptoplogic.com/">LaptopLogic.com</a>, your premier source for latest notebook reviews.<br /></blockquote><div><span class="Apple-style-span" style="color: rgb(0, 0, 238); text-decoration: underline;"><br /></span></div></div> <div style="margin: 0px 1px; padding-top: 1px;    background-color: #c3d9ff; font-size: 1px !important;    line-height: 0px !important;"> </div> <div style="margin: 0px 2px; padding-top: 1px;    background-color: #c3d9ff; font-size: 1px !important;    line-height: 0px !important;"> </div>
