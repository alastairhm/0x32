Quick update rather than a full write-up: since [pointing Claude Code at this blog's repo]({{< ref "claude-code-blog-cleanup.md" >}}) a few weeks back, the whole loop of writing, publishing, and maintaining this site has stopped being a chore.

The biggest change isn't any single fix — it's that the friction just isn't there any more. Drafting a post, sorting front matter, fixing up a GitHub Actions workflow that's drifted out of date, branching and PR-ing a change, merging it once it's built cleanly — all of that used to be enough faffing about that posts would sit as unfinished drafts for weeks. Now it's a five-minute conversation and it's live.

That's made a real difference to how often I actually post. The last couple of Arch + Hyprland posts went from draft to published same-day, workflow tweaks that would've been put off get done as soon as they're noticed, and I'm not sitting on half-written drafts because publishing them feels like a separate chore from writing them.

Nothing dramatic to report otherwise — just a low-traffic personal blog quietly getting easier to keep up, which is exactly the kind of unglamorous improvement that actually sticks.
