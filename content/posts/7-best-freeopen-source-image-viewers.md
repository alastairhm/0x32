It can render images according to properties of the display such as display resolution, color depth, and color profile. Other image viewers have advanced features like editing and web publishing.<br /><br />Some Linux users may not care much on whatever  image viewer they are using. But to those who are rather picky, they can always get and install other image viewers with different features to suit their needs.<br /><br />Here's a list of popular free and open source image viewers that you may want to check out:<br /></div><br /><span style="font-weight: bold;">imgSeek</span><br /><div><a href="http://www.imgseek.net/" target="Bwindow">imgSeek</a> is a photo collection manager and viewer with content-based search and many other features. The query is expressed either as a rough sketch painted by the user or as another image.<br /><br />Other key features:<br />* Transform images or batches automatically: Place text captions, change brightness, contrast, blur, etc. Apply lossless rotations automatically if jpegtran is available.<br />* Supported file formats are jpg, gif, bmp, png, xbm, and pnm. If you have ImageMagick installed, imgSeek will also support over 87 image formats.<br /><br /><a href="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEjowJtwQvUXgnlBUNJmi3MJtovxXJp0fR7KMSfHs8ymb3rY_1aCePUQTRW3D7lDvTVZ_VcrA6Tt2eLIm5s0tGK0KFC8Sew3WbKebD3tCRKojJWoCPYZrPPDOQcYXbUMqPtp1ZerkNCt5d4/s1600-h/imageseek.jpg" target="Bwindow"><img style="margin: 0px auto 10px; display: block; text-align: center; cursor: pointer; width: 320px; height: 237px;" src="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEjowJtwQvUXgnlBUNJmi3MJtovxXJp0fR7KMSfHs8ymb3rY_1aCePUQTRW3D7lDvTVZ_VcrA6Tt2eLIm5s0tGK0KFC8Sew3WbKebD3tCRKojJWoCPYZrPPDOQcYXbUMqPtp1ZerkNCt5d4/s320/imageseek.jpg" alt="" border="0" /></a><br /><span style="font-weight: bold;">Gwenview</span><br /><a href="http://gwenview.sourceforge.net/" target="Bwindow">Gwenview</a> is an image viewer for the KDE desktop environment. While it was available in KDE 3, the KDE 4 version has a simplified user interface, making it more suitable for quickly browsing through collection of images. It provides full-screen interface that can be used to display images as a slide-show.<br /><br />Other key features:<br />* Metadata comment editor<br />* Thumbnail image view of current directory<br />* Use of KIPI (KDE Image Plugins Interface) plugins for manipulating images<br /><br /><a href="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEigXH6_K18xPJjmLSceoVDHcj9S1MKnGw3_igrlUL0rWPQctJsqTgpPKYwgV3UNrzrnuWpE9_QTVXEBKBWGCS9LU1QYJJKji1hZgQsaaMFTRCfaGpQfA61UGi_WflJ2HNgicUPDT8-9xfE/s1600-h/750px-Gwenview-sl.jpg" target="Bwindow"><img style="margin: 0px auto 10px; display: block; text-align: center; cursor: pointer; width: 320px; height: 256px;" src="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEigXH6_K18xPJjmLSceoVDHcj9S1MKnGw3_igrlUL0rWPQctJsqTgpPKYwgV3UNrzrnuWpE9_QTVXEBKBWGCS9LU1QYJJKji1hZgQsaaMFTRCfaGpQfA61UGi_WflJ2HNgicUPDT8-9xfE/s320/750px-Gwenview-sl.jpg" alt="" border="0" /></a><br /><span style="font-weight: bold;">Eye of GNOME</span><br /><a href="http://projects.gnome.org/eog/" target="Bwindow">Eye of GNOME</a> is the official image viewer for the GNOME desktop environment. Unlike some other image viewers with advanced features, Eye of GNOME will only view images. It does, however, provide basic effects for improved viewing, such as zooming, full-screen, rotation, and transparent image background control.<br /><br />Supported file formats:<br />* ANI - Animation<br />* BMP - Windows Bitmap<br />* Graphics Interchange Format (GIF)<br />* ICO - Windows Icon<br />* JPEG - Joint Photographic Experts Group<br />* PCX - PC Paintbrush<br />…And a lot more;<br /><br /><a href="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEhF3zgQe2idDaZIpfFJqoIStrRwzaAfi0JliHTiFnCTreLRojTIEicu3_DenGZZhodvPgRX9QOHB8SJwl7KFrK5gutmEKLCahmqVDQUtpB9744TFqqbcEnVleKWda_5QuX5BD5a0nBvVmM/s1600-h/eog-screenshot.jpg" target="Bwindow"><img style="margin: 0px auto 10px; display: block; text-align: center; cursor: pointer; width: 320px; height: 283px;" src="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEhF3zgQe2idDaZIpfFJqoIStrRwzaAfi0JliHTiFnCTreLRojTIEicu3_DenGZZhodvPgRX9QOHB8SJwl7KFrK5gutmEKLCahmqVDQUtpB9744TFqqbcEnVleKWda_5QuX5BD5a0nBvVmM/s320/eog-screenshot.jpg" alt="" border="0" /></a><br /><span style="font-weight: bold;">KSquirrel</span><br /><a href="http://ksquirrel.sourceforge.net/" target="Bwindow">KSquirrel</a> is another image viewer for the KDE desktop environment with a disk navigator, file tree, thumbnails, extended thumbnails, dynamic format support, DCOP interface, KEXIF and KIPI plugins support. It supports more than 50 image formats, including PNG, JPEG, PSD, APNG, GIF, WMF, OpenEXR and many other.<br /><br /><a href="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEjF8NuJJ28iSTBU1uI8Y9ysl3iOq9ORp-LeXcYpbsi3lct0YBrGpkHjmaMXQfYJbQwKw0tZd43Ksy7kZ2_z1B7PExRDuWrFOIi0eOuc_ZDpXcqeCoBLQY5G5xZHYL4yRT3S_0NoVwjisLg/s1600-h/ksquir.jpg" target="Bwindow"><img style="margin: 0px auto 10px; display: block; text-align: center; cursor: pointer; width: 320px; height: 248px;" src="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEjF8NuJJ28iSTBU1uI8Y9ysl3iOq9ORp-LeXcYpbsi3lct0YBrGpkHjmaMXQfYJbQwKw0tZd43Ksy7kZ2_z1B7PExRDuWrFOIi0eOuc_ZDpXcqeCoBLQY5G5xZHYL4yRT3S_0NoVwjisLg/s320/ksquir.jpg" alt="" border="0" /></a><br /><span style="font-weight: bold;">gThumb</span><br /><a href="http://gthumb.sourceforge.net/" target="Bwindow">gThumb</a> is a feature-rich image viewer and organizer for the GNOME desktop environment. It was originally based on GQView, and is designed to have a clean, simple interface. gThumb allows the filesystem to be browsed for images. They can be organized into catalogs, or viewed as a slideshow. Folders and catalogs can be bookmarked, and comments may be added to images. Many basic image-editing features are included, such as: rotation, resizing, cropping, and image enhancing filters such as color, brightness and contrast adjustment. gThumb can also export Web-based albums with various theme templates.<br /><br /><a href="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEhBLJswg0sPAkZv54M7DCIaISbnar8ky8qqYTjlGaP4tbez3v66FBqW4Sz_Ues8Mom8jtMuC18cHvJj827E8M9iFqG38MNI4h7TPdylYrYnWSyw8VWJ77OT9gC2L3npz3E6PMeOwx0sSRw/s1600-h/gthumb.jpg" target="Bwindow"><img style="margin: 0px auto 10px; display: block; text-align: center; cursor: pointer; width: 320px; height: 226px;" src="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEhBLJswg0sPAkZv54M7DCIaISbnar8ky8qqYTjlGaP4tbez3v66FBqW4Sz_Ues8Mom8jtMuC18cHvJj827E8M9iFqG38MNI4h7TPdylYrYnWSyw8VWJ77OT9gC2L3npz3E6PMeOwx0sSRw/s320/gthumb.jpg" alt="" border="0" /></a><br /><span style="font-weight: bold;">GQview</span><br /><a href="http://gqview.sourceforge.net/" target="Bwindow">GQview</a> uses the GTK+ toolkit, designed to run on the X Window System. Its key features include single click file viewing, external editor support, thumbnail preview, and zoom features. Some image management features are also included.<br /><br />Other key features:<br />* One-click photo organizer/sorter<br />* Slideshow and full-screen modes<br />* Viewing Exif data for images<br /><br /><a href="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEganiQQoAJ9cm3sGN2K9CN4Kbfcj2J0MQ9qt4G5YAB7atKjUNWfOyM-Zc0JPfaoNSsLsirPkIw09AKi5tdN0acm1zfpZ5ez99TqwqThyphenhypheneVUnLz49VKjilkUsC4NelbpYaEmB-HG6OtT9XM/s1600-h/GQview.jpg" target="Bwindow"><img style="margin: 0px auto 10px; display: block; text-align: center; cursor: pointer; width: 320px; height: 233px;" src="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEganiQQoAJ9cm3sGN2K9CN4Kbfcj2J0MQ9qt4G5YAB7atKjUNWfOyM-Zc0JPfaoNSsLsirPkIw09AKi5tdN0acm1zfpZ5ez99TqwqThyphenhypheneVUnLz49VKjilkUsC4NelbpYaEmB-HG6OtT9XM/s320/GQview.jpg" alt="" border="0" /></a><br /><span style="font-weight: bold;">F-Spot</span><br /><a href="http://f-spot.org/" target="Bwindow">F-Spot</a> is lightweight image viewer and organizer for the GNOME desktop. It aims to have an interface that is simple to use, yet still supports advanced features such as tagging images and displaying and exporting Exif and XMP metadata. All major photographic image formats are supported, including JPEG, PNG, TIFF, DNG and several vendor-specific RAW formats (CR2, PEF, ORF, SRF, CRW, MRW and RAF).
