CorelDRAW and Adobe Illustrator are some of the most popular proprietary vector editors for Windows. But if you are looking for a capable <span style="font-weight:bold">free</span> alternative that can also work on your Linux box, there are a lot to choose from.<br /><br /><div style="text-align:justify">Here are some of the best Free and Open Source <span style="font-weight:bold">vector graphics editors</span>  that you should check out:<br /></div></div><br /><div style="text-align:justify"><br /><span style="font-weight:bold">Inkscape</span><br /><a href="http://www.inkscape.org/">Inkscape</a> is a well-known, full-featured vector graphics editor application for Linux. It has a main goal of becoming a powerful graphics tool while being fully compliant with the XML, SVG, and CSS standards. One of the prime concerns of the Inkscape project is interface consistency and usability. This involves efforts to follow the GNOME Human interface guidelines, universal keyboard accessibility, and convenient on-canvas editing. Inkscape has achieved important advancement in usability since the project started.<br /><br /><a href="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEhnfPA0yzU0LxIHlji915j7TyuBwHOZtXFqZQ8Z0xuYZRrfmGnq7WlbVNo-VIUKBsN8cu_ojTEcX4lh1qUmS8hNdbhGv2kk8JeiRfVR07sDf-nz3ABjs4JdO86LGfNIWlcR6xkX/s1600-h/inkscape.jpg"><img style="margin:0px auto 10px;display:block;text-align:center;width:400px;height:250px" src="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEhnfPA0yzU0LxIHlji915j7TyuBwHOZtXFqZQ8Z0xuYZRrfmGnq7WlbVNo-VIUKBsN8cu_ojTEcX4lh1qUmS8hNdbhGv2kk8JeiRfVR07sDf-nz3ABjs4JdO86LGfNIWlcR6xkX/s400/inkscape.jpg" alt="" border="0" /></a><br /><br /><span style="font-weight:bold">Xara Xtreme (Linux Edition)</span><br /><a href="http://www.xara.com/">Xara Xtreme</a> was originally developed for Windows but an open source version was later released for Linux. Xara Xtreme is known for its usability and fast rendering. It is also notable for being among the first vector graphics software applications to provide a fully anti-aliased display, advanced gradient fill, and transparency tools, features now common to many vector graphics editors. With interface almost identical to that of Inkscape and CorelDRAW, Xara Xtreme is considered to be quite easy to learn.<br /><br /><a href="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEgKOelAgITVKbArE3x3ef-nBJ5tLSnAVbiyNPwrB5KNT560FaxpHYuHKBlo-RsEaXssGquNzHyQzRVI_vv_0HfijXKl0gbRFaulmTINpPBArNlgJ_g6iGPKIfDCmK1fenrY1MSE/s1600-h/xara-xtreme-linux.jpg"><img style="margin:0px auto 10px;display:block;text-align:center;width:400px;height:326px" src="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEgKOelAgITVKbArE3x3ef-nBJ5tLSnAVbiyNPwrB5KNT560FaxpHYuHKBlo-RsEaXssGquNzHyQzRVI_vv_0HfijXKl0gbRFaulmTINpPBArNlgJ_g6iGPKIfDCmK1fenrY1MSE/s400/xara-xtreme-linux.jpg" alt="" border="0" /></a><br /><br /><span style="font-weight:bold">OpenOffice.org Draw</span><br /><a href="http://www.openoffice.org/product/draw.html">OpenOffice.org Draw</a> is a powerful graphics package that is part of the OpenOffice.org office suite. It features "connectors" between shapes, which are available in a range of line styles and facilitate building drawings such as flowchart. Currently, OpenOffice.org Draw officially supports exporting to SVG format, though with some limitations to be resolved. It is anticipated that as SVG and SVG filters evolve, users will be able to use Draw to edit the large-scale collection of SVG samples from Open Clip Art Library.<br /><br /><a href="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEg9mx9mrDvKPW_dBCo-xw8oNpVLfQOTCiHapDucl0sXddeCJzBwMBCTMK0FrHDR52cO1cZXS-SouO9xF1ER8d9T0olrURaLYQeaqxOoF9gH2gownZSjeDCL4PlfFZR3Dw6Mc2wv/s1600-h/OpenOffice.org-draw.jpg"><img style="margin:0px auto 10px;display:block;text-align:center;width:400px;height:300px" src="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEg9mx9mrDvKPW_dBCo-xw8oNpVLfQOTCiHapDucl0sXddeCJzBwMBCTMK0FrHDR52cO1cZXS-SouO9xF1ER8d9T0olrURaLYQeaqxOoF9gH2gownZSjeDCL4PlfFZR3Dw6Mc2wv/s400/OpenOffice.org-draw.jpg" alt="" border="0" /></a><br /><br /><span style="font-weight:bold">Skencil</span><br /><a href="http://www.skencil.org/">Skencil</a> is a unique drawing application in the sense that it is implemented almost completely in Python, a very high-level, object oriented, interpreted programming language, with the rest written in C for speed. In addition to the standard features (rectangles, ellipses, curves, text etc.) that you can expect from a vector graphics editor, Skencil also has some more advanced attributes like the possibility to bend text along a path.<br /><br /><a href="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEgLKi3NUdThyCqxGXT9XBvfSY0RBSpkVW4qvkoZ5ApwUPT6JzXGOAhMNwqpeqjX2lm3slBOx5BTLH0dxHBFAEMHqhIRtnOcwbM2PmvSuo-lP8p2SsJmShmyYLVFuLXgouZxjWTZ/s1600-h/skencil.jpg"><img style="margin:0px auto 10px;display:block;text-align:center;width:400px;height:375px" src="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEgLKi3NUdThyCqxGXT9XBvfSY0RBSpkVW4qvkoZ5ApwUPT6JzXGOAhMNwqpeqjX2lm3slBOx5BTLH0dxHBFAEMHqhIRtnOcwbM2PmvSuo-lP8p2SsJmShmyYLVFuLXgouZxjWTZ/s400/skencil.jpg" alt="" border="0" /></a><br /><br /><span style="font-weight:bold">sK1</span><br />From its project website, <a href="http://sk1project.org/">sK1</a> is described as an open-source illustration program that can substitute proprietary software like Corel Draw or Adobe Illustrator. It supports professional publishing features like CMYK color, separations, ICC color management and press-ready PDF output. It also has CorelDRAW formats importers and tabbed multi-document interface. sK1 is a fork of Skencil and was started by a small team of Ukrainian professionals.<br /><br /><a href="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEg06y55cLBL0RMZ3l8CziCaLsYosnYNlBnQsXf48wE_cnbXZYYPQr_drPfsPRX_TBRNqKnfDSwhEkpehWsxHwYIZzFxJrSMihr-nopTqZHInqnhe_MFIPaHohIBcQ6QNq6lwlqK/s1600-h/SK1.jpg"><img style="margin:0px auto 10px;display:block;text-align:center;width:400px;height:329px" src="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEg06y55cLBL0RMZ3l8CziCaLsYosnYNlBnQsXf48wE_cnbXZYYPQr_drPfsPRX_TBRNqKnfDSwhEkpehWsxHwYIZzFxJrSMihr-nopTqZHInqnhe_MFIPaHohIBcQ6QNq6lwlqK/s400/SK1.jpg" alt="" border="0" /></a><br /><br /><span style="font-weight:bold">Karbon14 </span><br /><a href="http://www.koffice.org/karbon/">Karbon14</a> (formerly known as Kontour) is part of the KDE office suite (KOffice). The name is a play on KDE and the radioactive isotope Carbon-14. Karbon14 boasts a user interface that is easy-to-use, highly customizable and extensible. It is also loaded with great features making it ideal for anyone who wants to create clipart, logos, illustrations or photorealistic vector images.<br /><br /><a href="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEggulLAAXRBHez7czM7-4e7y86DAj8E5HLzG2MvX4sqBmwazHa-MZFJ4be1n4a59jfQMEEXSjeMRWsesemJVUGCHwhgy2nFXON1JX_I3jnTiN-3x1Gec7nYJ49xsTXB3PJZEbHR/s1600-h/karbon14.jpg"><img style="margin:0px auto 10px;display:block;text-align:center;width:400px;height:250px" src="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEggulLAAXRBHez7czM7-4e7y86DAj8E5HLzG2MvX4sqBmwazHa-MZFJ4be1n4a59jfQMEEXSjeMRWsesemJVUGCHwhgy2nFXON1JX_I3jnTiN-3x1Gec7nYJ49xsTXB3PJZEbHR/s400/karbon14.jpg" alt="" border="0" /></a><br /><span style="font-weight:bold">Xfig</span><br /><a href="http://xfig.org/">Xfig</a> is an interactive drawing tool that runs under the X Window System. In xfig, figures may be drawn using objects such as circles, boxes, lines, spline curves, text, etc. It is also possible to import images in formats such as GIF, JPEG, EPSF (PostScript), and many others. Xfig saves figures in its native Fig format, but they may be converted into various formats.<br /></div><br /><div style="text-align:center"><a href="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEiplxvQBQNecNuDt0eBP9WoGa1EkbuhzjyIylDkEklYapZyOWrLJq78L2CRDes7JFL-TAOc8G8_AcaiLlgFmvjpsZ4Mh1Et2VcW6U9mFBpxzRPQ4amnfOtZs2aXKQCMyX9p7K-o/s1600-h/Xfig.jpg"><img style="margin:0px auto 10px;display:block;text-align:center;width:400px;height:322px" src="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEiplxvQBQNecNuDt0eBP9WoGa1EkbuhzjyIylDkEklYapZyOWrLJq78L2CRDes7JFL-TAOc8G8_AcaiLlgFmvjpsZ4Mh1Et2VcW6U9mFBpxzRPQ4amnfOtZs2aXKQCMyX9p7K-o/s400/Xfig.jpg" alt="" border="0" /></a><br /></div><div><img width="1" height="1" src="https://blogger.googleusercontent.com/tracker/5023590240909870844-3572698277167850966?l=www.junauza.com" /></div><div> <a href="http://feeds.feedburner.com/~ff/SimplyJun?a=j-CaxymheNo:k8XKE5yzzLM:yIl2AUoC8zA"><img src="http://feeds.feedburner.com/~ff/SimplyJun?d=yIl2AUoC8zA" border="0" /></a> <a href="http://feeds.feedburner.com/~ff/SimplyJun?a=j-CaxymheNo:k8XKE5yzzLM:dnMXMwOfBR0"><img src="http://feeds.feedburner.com/~ff/SimplyJun?d=dnMXMwOfBR0" border="0" /></a> <a href="http://feeds.feedburner.com/~ff/SimplyJun?a=j-CaxymheNo:k8XKE5yzzLM:7Q72WNTAKBA"><img src="http://feeds.feedburner.com/~ff/SimplyJun?d=7Q72WNTAKBA" border="0" /></a> <a href="http://feeds.feedburner.com/~ff/SimplyJun?a=j-CaxymheNo:k8XKE5yzzLM:V_sGLiPBpWU"><img src="http://feeds.feedburner.com/~ff/SimplyJun?i=j-CaxymheNo:k8XKE5yzzLM:V_sGLiPBpWU" border="0" /></a> <a href="http://feeds.feedburner.com/~ff/SimplyJun?a=j-CaxymheNo:k8XKE5yzzLM:gIN9vFwOqvQ"><img src="http://feeds.feedburner.com/~ff/SimplyJun?i=j-CaxymheNo:k8XKE5yzzLM:gIN9vFwOqvQ" border="0" /></a> </div><img src="http://feeds.feedburner.com/~r/SimplyJun/~4/j-CaxymheNo" height="1" width="1" /></div><br /><div style="margin: 0px 2px;
